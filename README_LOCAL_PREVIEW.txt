ReadyStack local preview

Open index.html from the project root.

For service pages, open:
- website-design/index.html
- website-redesign/index.html
- email-setup/index.html
- website-maintenance/index.html

If you open a folder directly in a browser using file://, the browser may show an "Index of" directory listing. That is normal for local folders. The site links now point directly to each index.html file to avoid this.

Recommended preview:
python3 -m http.server 8000
then open http://localhost:8000
