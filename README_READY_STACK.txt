ReadyStack connected site package

Place these files at your project root.
- index.html
- css/base.css, layout.css, components.css, animations.css
- js/main.js, animations.js, dashboard.js
- website-design/index.html
- website-redesign/index.html
- email-setup/index.html
- website-maintenance/index.html

The homepage links to CSS/JS with css/ and js/ paths. Service pages link with ../css/ and ../js/ paths.
